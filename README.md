# FinTrack
A command-line personal finance tracking application built in Python using OOP principles.

FinTrack lets a user log expenses and income, register assets and liabilities and review their financial history, all through the same  terminal menu. 

Its currently an MVP, everything lives in memory for the session and no persistent storage.

FEATURES:
1) Log Expense - record our spending across 10 categories (Food & Dining, Transportation, Shopping, Bills & Utilies, Entertainment, Health & Medical, Educaiton, Travel, Personal, Miscellaneous)
2) Log Income - record income aross 7 categories (Salary, Freelance / Business, Interest, Bonuses, Gifts, Refunds, Others)
3) Register Assets - track investments across 8 categories (Stocks, Mutual Funds, ETFs, Real Estate, Gold, Bonds, Crypto, Bank Deposits)
4) Rgister Liabilities - track debts across 7 categories (Car Loan, Home Loan, Educational Loan, Personal Loan, Credit Card Debt, Business Loan, Others)
5) View Account Details - see basic user profile info
6) View History - browse a log of past expenses, income, assets or liabilities

TECHNOLOGY & CONCEPTS:
1) Python 3.x
2) OOP - User, Expense, Asset, Liability classes
3) Input vaidation using try/except and bounded retry loops
4) Datetime module for date logging (dd-mm-yyyy format)

FUTURE ROADMAP:
1) Persistent storage (file based or database) so data survives between sessions
2) Editing / deleting logged entries
3) Summary / analytics overview - totals, net worth and spending by category)
4) Budget Tracking
